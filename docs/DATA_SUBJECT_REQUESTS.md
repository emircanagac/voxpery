# Data Subject Request Process

The in-app ZIP is a bounded convenience export: it includes the latest 20,000 authored server messages and 20,000 authored DMs plus eligible user-owned files. It is not a complete GDPR/KVKK access response.

## Hosted-service requests

1. Send the request from the account email to `voxpery@gmail.com` and identify the right being exercised.
2. The operator records the request in a restricted case log and verifies identity using the minimum additional information necessary. Never request an account password by email.
3. Preserve only data relevant to the request and check for third-party rights, legal holds, and disclosure restrictions.
4. Search applicable account, relationship, message, attachment, moderation, security, audit, and backup metadata sources beyond the self-service limits.
5. Deliver the response through an authenticated, time-limited channel and record completion without copying content into general application logs.
6. Apply correction, deletion, restriction, objection, or portability actions where legally required, and explain any lawful refusal or limitation.

Requests and identity evidence must be access-restricted and deleted after the applicable legal/claims retention period. Operators must track statutory response deadlines for the requester's jurisdiction.
